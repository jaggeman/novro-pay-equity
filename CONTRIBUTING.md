# Contributing

1. Open an issue for a calculation or API change.
2. Add a test that fails for the intended reason.
3. Implement the smallest change that makes it pass.
4. Run `npm run check`.
5. Explain the formula, unit, rounding, anonymity and compatibility impact in
   the pull request.

Do not submit real employee data, customer names, credentials or proprietary
HRIS exports. Use synthetic fixtures.

Contributions are accepted under AGPL-3.0-only. A separate contributor
agreement may be required for contributions intended for dual licensing.
