# Security policy

Do not report vulnerabilities that could expose salary or identity data in a
public issue. Use GitHub's private vulnerability reporting for this repository.

Submit a private report at
<https://github.com/jaggeman/novro-pay-equity/security/advisories/new>.

Supported version: the latest tagged release.

Reports should include the affected version, impact, minimal reproduction and
suggested mitigation. Never include real employee or customer data.
